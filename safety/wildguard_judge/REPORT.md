# 四组回答按 WildGuard 自动评分（512-token 版本）

日期：2026-10-15。本报告只对已生成的 512-token 四组回答做离线自动评分，不重新生成回答或训练模型。WildGuard 是独立自动评判器；它不参与 B/D 防护策略。1024-token 截断诊断不并入本报告。

## 评判器与配置

模型 `allenai/wildguard`，revision `cbba4823f3e8020e5a74a5e29bf85072def6f2ff`，许可 `Apache-2.0`。官方模型卡要求同意 AI2 Responsible Use Guidelines 并完成访问信息；本运行使用本机获准凭据。模型输入模板按[官方模型卡](https://huggingface.co/allenai/wildguard)的 `instruction_format`，包含请求及待评回答；tokenizer 使用慢速版并 `add_special_tokens=false`。输出按官方格式解析 `Harmful request`、`Response refusal`、`Harmful response` 三项 yes/no（回答字段允许 n/a）；解析器对每个字段单独记录有效性，并保留官方 `is_parsing_error`。

Transformers `5.5.4`，PyTorch `2.9.1+cu128`，Python `3.11.17`；BF16、CUDA、SDPA、batch=1、greedy (`do_sample=false`, `num_beams=1`)、`max_new_tokens=128`。不静默截断；若模板输入加生成预算超过上下文长度，该条记 unknown。

模型文件共 14,496,898,091 bytes（safetensors 14,496,097,336 bytes）；未下载重复 `.bin` 权重。缓存为一份。

## 主要观察

main 下 A→B 的有害请求有害回答率变化为 -1.86 点（95% CI -2.92 至 -0.93），正常请求拒答代理变化为 +2.75 点。C→D/main 对应变化为 -1.19 点、正常请求拒答 +2.22 点。

纯 RMU 对原模型（A→C）的有害请求有害回答差值为 -0.80 点（95% CI -1.73 至 +0.13），区间含 0，当前样本和评判器无法分辨这一指标的变化方向。已有 main 策略时 B→D 差值为 -0.13 点（95% CI -0.40 至 +0.00）；strict 下 B/D 未观察到有害回答阳性。对应的正常请求拒答变化需同时考虑，不能只依据安全方向的自动评分选择方法。

上述判断只适用于固定512-token输出，且区间未包含评判器自身系统误差；不能解释为真实有害率或已证实的安全提升。

## 512-token 预算与范围

- `original`：512 token 截停 869/1699 (51.15%)；自然 EOS 830/1699。
- `rmu80`：512 token 截停 844/1699 (49.68%)；自然 EOS 855/1699。

指标只适用于当前固定的 512-token 生成回答，不外推到更长回答或完整无限生成。原始 A/C 回答与 B/D 用户最终收到的回答分别评分；拦截后固定拒答也作为最终回答评分。每个完全相同的请求—回答对只运行一次 WildGuard，再映射到全部组别和策略。Qwen3Guard 判断、组别、输入标签和预期结果均不传给 WildGuard。

## 限制

WildGuard 是自动评判器，可能误判；本报告没有人工复核标签，也没有独立第三方裁定。拒答与回答有害性独立统计，拒答不自动视为安全。正常请求拒答率仅为过度拒答代理，未测任务正确率/帮助性。安全指标差异的区间只涵盖固定样本重抽样误差，不涵盖评判器系统误差。
