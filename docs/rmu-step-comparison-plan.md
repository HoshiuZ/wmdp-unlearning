# 纯RMU训练长度对照：固定方案

本轮只改变训练长度。从固定Qwen3-4B-Instruct-2507原始参数重新开始，一条连续轨迹执行120次优化器更新，在40、80、120步固定保存增量并评测，不按成绩改变时点或超参。

固定hook12（零起始decoder block输出），只更新10/11/12层down_proj.weight；alpha2、gamma1、steering32、lr5e-5恒定、无warmup、adamw_torch、weight_decay0、clip1、BF16/SDPA、batch1×累积16、seq256、seed/data_seed42。正式解析配置除训练长度和输出/说明元数据外必须与历史h12_a2_s32_fixed40一致。沿用formal_blocks_v1缓存文章块及原采样器；2048个anchor块，一遍128次更新，本轮120步不会跨遍。

恢复历史保存控制方向，在第0步文章验证时消耗历史首次随机向量抽样，然后才启用通用随机状态保护。文章验证沿用0及每10步；retain NLL仅监控。开发评测只在40/80/120步进行；历史10/20步开发评测已保护RNG，不影响前40步轨迹。

第40步核查索引、token预算、逐步损失、控制向量、参数SHA和开发逐题预测；核查前不更新第41步。若不完全一致，保持同一进程中的优化器/调度器，等待证据解释；不能用旧增量权重冒充精确续训。匹配时复用历史40步全量逐题结果并重新核对算术、题目和提示；否则在解释并允许继续后新评测40步。

训练完成释放训练状态，由单独一个评测模型串行从原始参数应用80/120步增量。0-shot、无chat/system、BF16/SDPA、batch1、精确归档loglikelihood请求；Bio1273、MMLU14042。开发集固定Bio256、MMLU1710，分别报告等权及按全量科目人数加权MMLU。保留原定义10个生物相关科目和47个其他科目。

空间预算按历史真实增量估算，计入三个缓存载荷、压缩/清理暂存重复占用、文本结果及余量，另留1GiB底线；保存前重查。不删除历史权重或缓存，不付费扩容。新LFS额度在没有可信账号账单证据时记未知，未知时仅推送文本与清单，增量留在本地持久数据盘，不自动上传或假称远端备份。

入口：`scripts/run_rmu_step_comparison.py --run`；串行评测：`scripts/evaluate_rmu_step_comparison.py`。环境前缀与完整命令保存在`logs/rmu_step_comparison_preflight.json`。新的必要CPU探针独立进程执行，正式过程重新加载原模型并设seed42，不复用探针优化器或随机状态。

增量不含优化器状态，不能独立恢复精确训练轨迹。遇非有限数值、无法解释的差异或资源不足则停并记录；不因MMLU超过2/3点停止。本轮不追加步数或改变方法。
