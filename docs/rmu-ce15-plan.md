# CE保留权重1.5倍：双seed匹配对照计划

本轮仅新增CE权重乘1.5，从0.060028908617563034到0.09004336292634455。固定原始Qwen3-4B-Instruct-2507起点、hook12输出（0-based）、10/11/12 down_proj.weight、alpha2、steering32、lr5e-5、40步、batch1/累积16、AdamW与clip1。Sim不加入loss。seed42、43各一组，与各自已有CE1倍结果匹配，控制向量与实际采样顺序/预算须逐值一致；两个seed之间方向与采样本就不同。

先每组独立原始起点两步CUDA检查，再串行训练，两组均保存10/20/40步。每组固定第40步全量Bio1273、MMLU14042，预先承诺不因开发分数改变、取消或重选。沿用归档0shot评分请求、BF16/SDPA、batch1、无聊天模板、loglikelihood。完整配置/seed与各自旧实验除CE倍率及路径/说明外必须相同；逐题请求复核。

主要判据为每个seed分别满足MMLU较原始下降不超过2点，并评估Bio相对各自CE1倍的代价。两次均值/样本标准差只作描述，不替代单次约束。结果含历史已观察test，属于固定方案探索。若失败如实保留，不自动追加系数搜索、seed或其他方法。
